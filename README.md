# Курсова робота

## Тема: "Новинний портал огляду сучасних розробок Українського ВПК"
### Назва проекту: "ВПК-news"
### Дисципліна: "Веб-технології та веб-дизайн"

---

## 1. Загальний опис проекту

Веб-додаток "ВПК-news" є повнофункціональним односторінковим додатком (Full-Stack SPA), створеним для систематизації та публікації інформаційних оглядів сучасних розробок українського оборонно-промислового комплексу. Додаток надає користувачам можливість ознайомлення з технічними характеристиками зразків озброєння, фільтрації матеріалів за категоріями, повнотекстового пошуку, перегляду фотоматеріалів та керування вмістом через панель адміністратора.

### Функціональні можливості:
- Головна сторінка: інтерактивний слайдер ключових зразків техніки та блок десяти останніх оглядів.
- Каталог публікацій: пошук у реальному часі, фільтрація за категоріями озброєння (БПЛА, Артилерія, Морські дрони, Бронетехніка, РЕБ, Ракетне озброєння), сортування за датою.
- Сторінка огляду: повний текст матеріалу, технічні характеристики, категорія, автор та дата публікації.
- Фотогалерея: перегляд зображень техніки з фільтрацією за родами озброєнь та модальним вікном перегляду на базі стандарту HTMLDialogElement.
- Довідковий розділ ("Про сайт"): інформація про мету створення ресурсу та використовуваний технологічний стек.
- Контактний розділ: контактні дані редакції, форма надсилання повідомлень та вбудована інтерактивна карта Google Maps.
- Панель керування (CMS): авторизація адміністратора на основі JSON Web Tokens (JWT), створення, редагування та видалення оглядів, завантаження зображень на сервер.

## 2. Технологічний стек

### Клієнтська частина (FrontEnd):
- Бібліотека інтерфейсу: React 18
- Мова програмування: TypeScript
- Інструмент збирання: Vite 5
- Маршрутизація: React Router DOM v6
- Препроцесор стилів: SCSS (Sass, сучасний синтаксис Dart Sass) з використанням змінних, міксинів та ієрархічної вкладеності
- Модальні вікна та підказки: стандартний HTML-елемент dialog із сучасними CSS-анімаціями (at-rule @starting-style, transition-behavior: allow-discrete) та Popover API із CSS Anchor Positioning

### Серверна частина (BackEnd):
- Платформа виконання: Node.js
- Веб-фреймворк: Express
- База даних: SQLite (бібліотека better-sqlite3 у режимі Write-Ahead Logging)
- Автентифікація: JSON Web Tokens (JWT), криптографічне хешування паролів за допомогою bcryptjs
- Збереження медіа: обробник завантаження зображень з валідацією формату та контролем розміру файлів
- Роздача клієнтської частини: підтримка продакшен-режиму, за якого Express віддає скомпільований клієнтський бандл

## 4. Специфікація REST API

| Метод | Маршрут | Опис | Доступ |
|---|---|---|---|
| POST | /api/auth/login | Автентифікація користувача, повернення JWT токена | Публічний |
| POST | /api/auth/register | Реєстрація нового облікового запису | Публічний |
| GET | /api/news | Отримання каталогу новин (параметри: search, category, sort) | Публічний |
| GET | /api/news/top | Отримання десяти останніх опублікованих оглядів | Публічний |
| GET | /api/news/:id | Отримання повної інформації про огляд за ID | Публічний |
| POST | /api/news | Створення нового огляду техніки | Тільки адміністратор (JWT) |
| PUT | /api/news/:id | Редагування існуючого огляду за ID | Тільки адміністратор (JWT) |
| DELETE | /api/news/:id | Видалення огляду за ID | Тільки адміністратор (JWT) |
| GET | /api/gallery | Отримання фотографій галереї (параметр: category) | Публічний |
| POST | /api/upload | Завантаження графічного файлу на сервер | Тільки адміністратор (JWT) |

## 5. Інструкція зі встановлення та запуску

### Системні вимоги:
- Node.js версії 18.x або вище
- Пакетний менеджер npm

### 1. Встановлення залежностей
Для інсталяції пакетів клієнтської та серверної частин виконайте у кореневому каталозі:
```bash
npm run install:all
```

### 2. Запуск у режимі розробки
Одночасний запуск сервера Express та сервера швидкої розробки Vite:
```bash
npm run dev
```
- Клієнтська частина: http://localhost:5173
- Серверне REST API: http://localhost:3001/api

### 3. Збирання проекту для продакшену
Компіляція клієнтських ресурсів у каталог client/dist та серверного коду в каталог server/dist:
```bash
npm run build
```

### 4. Запуск скомпільованого сервера
Запуск сервера, який роздає REST API та зібраний клієнтський SPA-додаток на єдиному порті:
```bash
npm start
```
- Додаток доступний за адресою: http://localhost:3001

### 5. Розгортання на хмарному хостингу (Render.com)
Для розгортання веб-сервісу на платформі Render.com:
- Build Command: `npm run build`
- Start Command: `npm start`
У корені проекту додано файл конфігурації `render.yaml` (Render Blueprint), який забезпечує автоматичне налаштування параметрів збирання та запуску сервісу на платформі.

## 6. Обліковий запис адміністратора за замовчуванням

Під час першого запуску сервера база даних автоматично наповнюється тестовими даними та створює обліковий запис адміністратора:
- Логін: admin
- Пароль: Viti@!2101
- Роль: admin

Пароль зберігається у хешованому вигляді із застосуванням солі за алгоритмом bcrypt. Для виконання операцій створення, редагування та видалення новин передається сесійний JWT-токен у заголовку Authorization: Bearer <token>.
